## 📌 Project Overview
Development teams using Jenkins face challenges tracking pipeline performance because build execution durations, queue times, and failure histories are scattered across multiple job pages. 

This project centralizes CI/CD metrics into a unified dashboard, displaying success rates, build duration trends, queue lengths, and flaky job indicators.

## 🛠️ Tech Stack
- **CI/CD Platform:** Jenkins (Local/Demo Environment), Groovy, Jenkinsfile
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Data & Charts:** Jenkins REST API, Chart.js
- **Tools:** Git, GitHub, VS Code
