## 📌 Project Overview
Development teams using Jenkins face challenges tracking pipeline performance because build execution durations, queue times, and failure histories are scattered across multiple job pages[cite: 1]. 

This project centralizes CI/CD metrics into a unified dashboard, displaying success rates, build duration trends, queue lengths, and flaky job indicators[cite: 1].

## 🛠️ Tech Stack
- **CI/CD Platform:** Jenkins (Local/Demo Environment), Groovy, Jenkinsfile[cite: 1]
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)[cite: 1]
- **Data & Charts:** Jenkins REST API, Chart.js[cite: 1]
- **Tools:** Git, GitHub, VS Code[cite: 1]
